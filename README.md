# alakhag.github.io

Personal site of Alakh Aggarwal. Plain static HTML served by GitHub Pages (no Jekyll; see `.nojekyll`).

- Blog posts: write markdown in `content/posts/`, then run `pip install markdown pyyaml && python3 tools/build.py`, and commit the generated `posts/` folder.
- Math in posts uses `$...$` / `$$...$$`, rendered by the self-hosted KaTeX in `assets/katex/`.
